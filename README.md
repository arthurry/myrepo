# Fore Studio website

A responsive, static six-page website for Fore Studio.

## Files
- `index.html`, `about.html`, `services.html`, `cloud-architecture.html`, `ai-transformation.html`, `contact.html`
- `assets/images/fore-studio-logo.png` and `fore-studio-logo-compact.png` — locally hosted Fore Studio logo variants
- `assets/images/` — five local SVG illustrations
- `assets/css/style.css`
- `assets/js/main.js`

## Preview locally
Open `index.html` in a browser, or run a local server from this folder:
`python3 -m http.server 8000`

## Before publishing
- Replace `hello@forestudio.example` with your real contact email.
- Connect the contact form to a form service or backend; the current form uses `mailto:`.
- Review all copy and branding details.
- The logo and illustrations are local SVG files; no third-party image CDN is required.
